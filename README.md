# S K Groups - Premium Poultry Solutions

Welcome to the **S K Groups** repository! This is a modern, responsive website built for S K Groups, located in Avaragolla, Davanagere, Karnataka. They are suppliers of BV380 and BV300 Birds, poultry cages, feed, and other poultry equipment and services.

## 📂 Project Structure

The project consists of the following pages and files:
- **`index.html`**: The home page featuring services, business trust-factors, stats, and navigation.
- **`shop.html`**: The page listing premium poultry solutions (hens, cages, feed, equipments).
- **`about.html`**: Information about S K Groups, their values, journey, and team.
- **`contact.html`**: A clean, premium contact/enquiry page.
- **`style.css`**: Centralized stylesheet specifying variables, typography, layouts, and responsive media queries.
- **`script.js`**: Core script handling interactions such as mobile menus, smooth scrolling, or other page transitions.

## 🛠️ Tech Stack & Features
- **Frontend Core**: Vanilla HTML5 & CSS3.
- **Styling & Fonts**: Google Fonts (Inter & Outfit), FontAwesome for modern icons.
- **Interactions**: Responsive mobile navigation, floating WhatsApp contact widget.
- **Clean Structure**: Designed with semantic markup and responsive CSS grid & flexbox.
